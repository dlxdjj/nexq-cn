# STT connection probe

`stt-probe.wav` is a fixed synthetic English sample generated locally with
Windows System.Speech / Microsoft Zira Desktop, PCM 16 kHz, mono, 16-bit.
Text: “Hello. This is a speech recognition test.”

No microphone, meeting, or personal recording is included. The explicit Whisper
API connection-test button uploads this sample to OpenAI (normal API fees may
apply). Unit tests use no network and do not upload the fixture.
